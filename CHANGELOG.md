# Changelog

## 1.0.0 - 2026-08-13

### Added

- Added one stacked upgrade node per enchantment.
- Added current-level and next-cost details to enchantment tooltips.
- Added content-centered camera resets whenever the enchanting interface refreshes.
- Added Shift + hold removal for stacked enchantments that still have another upgrade.

### Compatibility

- Minecraft 1.21.1 with NeoForge 21.1.209 or newer.
- Requires Immersive Enchanting 6.0 or newer.
- Client-side only and intentionally configuration-free.
